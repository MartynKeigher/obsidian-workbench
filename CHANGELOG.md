# Changelog

All notable changes to Workbench are listed here, newest first.

## [1.1.1] - 2026-11-24

### Fixed
- The help and settings icons stay in the ribbon when the ribbon is shown. 1.1.0 moved them into the
  vault footer even with the ribbon on.

### Docs
- New README screenshots and cover image.

## [1.1.0] - 2026-11-24

### Changed
- Design tokens synced to Workbench UI v0.7.0: warmer parchment hover, row, tile and chip fills, a deeper
  green header bar and accent, and new ink colors for headings, captions, bold text and the status bar.
- Light mode now reads these tokens directly instead of repeating hard-coded colors. Dark mode is unchanged.

### Fixed
- With **Show ribbon** turned off, the vault help and settings icons no longer sit half off the window
  edge. They now appear at the end of the vault footer row, or at the foot of the rail when the left
  sidebar is collapsed.

## [1.0.1] - 2026-11-12

### Fixed
- With the Hidden window frame style, the collapsed right sidebar toggle is no longer hidden under the
  minimize, maximize and close buttons, and it lines up with the tab-list arrow beside it.

### Docs
- README updated with badges and install steps from Obsidian's theme gallery.

## [1.0.0] - 2026-11-12

### Added
- First release of Workbench: warm parchment panels, deep green headings and a dark top bar, in light
  and dark modes.
- Built-in **Source Sans 3** and **Source Code Pro** fonts.
- Styling for callouts, canvas, code, embeds, properties, tables, tags, tasks, sidebars, the ribbon,
  status bar, prompts and mobile.
